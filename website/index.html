需要 Root 或额外系统权限吗？

Linux 与普通 Agent 任务无需 Root。无线 ADB、Shizuku、无障碍和安装 APK 等能力按需配置，具体操作仍受 Android 系统权限限制。

可以离线使用吗？

已安装的 Linux、终端和本地文件操作可以离线使用。AI 是否需要联网取决于模型端点；本地推理需要另行准备运行环境与模型，APK 不内置模型权重。

后台任务和定时计划会准点执行吗？

工作流支持后台运行和计划调度。建议允许通知并调整电池优化设置；Android 的后台限制仍可能延迟或中断任务。

换设备时如何备份？

设置中可导出与恢复本地数据。备份不包含 RootFS、工作区实际文件和模型凭据，这些内容需另行备份。查看备份范围 ↗
