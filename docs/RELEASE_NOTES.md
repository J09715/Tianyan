## 🆕 v0.17.6 补充

- **Git 面板底部导航不再与主界面导航重叠**：状态/分支/提交原先是固定在底部的悬浮页签栏，正好压在 App 自己的底部中枢导航（天衍/智枢/工坊/乾坤）上，两层导航叠着显示还互相抢触摸。改用 `SecondaryTabRow` 放到内容上方，与设置页同一套页签语义；
- **去掉重复的改动统计**：面板顶部摘要卡与状态页的「工作区概览」卡展示的是同样四个数字，并排出现会让人以为两处口径不同。只保留顶部那张；
- **术语澄清**：面板头部「Git 工作区」改为「Git 仓库」——本 App 里「工作区」特指工坊的项目目录，两个词混用会让人误以为这个面板管的是工坊工作区；
- **移除「进群取离线包」入口**：环境体检是排障路径，把用户支去加群解决不了环境缺失，群链接失效时更是死路。只保留「插件中心安装」一条路径，顺带清掉加群逻辑、群号常量与相关字符串。

## 🆕 v0.17.5 补充

### 插件包与安装教程修复

- **删掉一个装不上的重复插件包**：`assets/plugins/` 下同时存在 `qemu-x86_64-compat` 与 `qemu-x86-64-compat`，两者 `id` 相同但前者没有 payload、没有安装步骤——插件中心按 id 索引，这个包永远装不上；
- **修正下载教程里会让安装失败的文件名**：`android-suite-offline/DOWNLOADS.md` 的 PowerShell 示例把 Flutter 包重命名成 `flutter-source-arm64.tar.gz`，而安装脚本与 `SHA256SUMS` 要的是 `flutter-linux-arm64-android-only-slim.tar.gz`。照教程做完仍会报「缺文件」；顺带把最大的那个归档（约 848 MB）补进校验清单；
- **安装引导说清真实包格式**：插件中心首次引导原写「选择 zip 文件」，而离线包是 `.txplugin`，拿到正确文件的用户会以为自己下错了；
- **hermes-agent 的注册表步骤改为显式说明**：该工具由专用安装器（下载官方 `install.sh`）安装，注册表里原有的 stub 步骤永远不会被执行，留着会让维护者以为改注册表就能改安装行为。

### 新增回归测试

- `PluginPackageIntegrityTest`（7 项）：插件 id 唯一、`LOCAL_PACKAGE` 必须带 payload 与可运行步骤、`SHA256SUMS` 指向真实文件、安装脚本引用的归档名与下载文档一致、脚本为 POSIX 且无 CRLF、无上游品牌残留；
- `ToolRegistryIntegrityTest`（8 项）：注册表 id 唯一、下载必须带 `--fail`（否则 404 也会当成功）、校验路径必须是真的下载目标、调用的运行时必须声明依赖或自行安装、`commandLinks` 覆盖 `launchCommand`。

## 🆕 v0.17.4 补充

- **红队 UI 用回项目现有控件**：上一轮手搓的页签条 / 筛选胶囊 / 下拉 / 列表行，全部换成 `SecondaryScrollableTabRow` + `Tab`、`FilterChip`、`ExposedDropdownMenuBox`、`Surface`，与设置页同一套语义；
- **git 缺失不再伪装成「网络问题」**：rootfs 里不一定带 git，而读操作拼了 `|| true` 把「git: not found」变成空输出、写操作直接报原文、凭证探测因缺 curl 被判成「网络不通」。现在所有 git 操作先过 `ensureGit()`（探测 → 按 apt/apk/dnf 安装 → 装不上给可执行指引），凭证探测缺 curl 时明确说明不是网络问题。

## 🎉 版本亮点

v0.17.0 把红队能力从「能跑」补齐到「能看能改」：

- **RedTeam 控制台上线**——对话里原先只有一块单页概览，现在是多页签控制台：资产测绘、智能体提示词、技能库，外加保留原有能力的概览页签。页签顺序与上游 `client.js` 一致；
- **角色提示词真的会留下来**——此前用户改过的角色提示词只存内存，进程一死就静默变回内置文案且没有任何提示。现在落库到 `prompt` 事实（`id = prompt:<role>`），与阶段/得分点覆盖层同一套持久化；
- **技能库可以新建、编辑、删除了**——此前 `skill_add` 只登记事实、不写正文，面板存不了技能。现在按上游 `SKILL.md` frontmatter 语义落到应用自己的技能库，内置技能拒改拒删并给出原因，不静默跳过。

## 🐛 修复

- **「继续」后任务显示完成却没有回答**：`TurnRunner` 加了失败关闭分支——模型既没给出可展示文本也没发起工具调用时，本轮判失败并说明原因，不再当作正常结束；
- **工具轮数耗尽被当成成功**：达到最大工具轮数时返回明确失败（`已达到最大工具轮数（N），任务尚未确认完成`），不再静默收尾；
- **工具无输出时面板空白**：工具返回空文本时补一条明确说明，不再出现「跑完了但什么都没有」；
- **工具输出截断**：超长输出保留头部并附显式截断提示，不再无提示地砍掉尾部。

## 🧱 内部

- 新增 `core/model/RedTeamConsoleModel`：面板投影层（纯 Kotlin）。过滤、排序、网段、统计、图谱口径与上游 `listAssets` 一一对应；面板直接读结构化行，不去正则解析工具输出——工具输出改一个字面板就瞎了；
- 事实库新增 `byKinds` 批量读：`recent` 的 500 条上限对面板不够（上游默认就展示 400 台资产），越过会被显示成「记录变少了」；
- 图谱改用确定性环形布局：移动端跑力导向迭代会掉帧，且布局每次都在抖，用户点开的瞬间看到的位置和下一眼不一样；
- 单元测试 918 → 1017（新增控制台投影 10 项、角色提示词与技能库 6 项）。

### 与上游的有意分歧

- 时间戳存 epoch 毫秒，不是 ISO 字符串；
- 不另建靶标表：一个绑定了红队模式的会话就是一个靶标，面板用会话选择代替上游的 `current` 指针；
- 不记录 `scan_run` 批次表（批次元信息不落库）；
- 知识库按会话隔离，不跨靶标共享 POC。
