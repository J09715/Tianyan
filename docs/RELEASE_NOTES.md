> **版本号**：v0.17.1（`appVersionName = 0.17.1`，`appVersionCode = 59`）
> **支持范围**：Android 10+ · arm64-v8a（无 Root / PRoot 沙箱）

## 🆕 v0.17.1 补充

- **导入不再丢网段归属**：`import_bundle` 的 `segments` 此前只计数、行被直接丢弃，上游写入的 `org` / `asn` / `country` / `city` 全部静默消失。现落为 `segment` 事实，并按上游 `COALESCE` 语义合并，后续导入不带 `org` 时不会清空先前值；
- **面板终于能改并发智能体数**：读写逻辑早已齐备却没有入口，`setAgentsMax` 在上游是使用中最常调的一项。现补上概览页签的并发卡片，并如实标注上限来源（设置项 / 环境变量 / 默认值）——被环境变量压住时没有这行提示，用户会以为界面坏了。

---

## 🎉 版本亮点

v0.17.0 把红队能力从「能跑」补齐到「能看能改」：

- **RedTeam 控制台上线**——对话里原先只有一块单页概览，现在是多页签控制台：资产测绘、智能体提示词、技能库，外加保留原有能力的概览页签。页签顺序与上游 `client.js` 一致；
- **角色提示词真的会留下来**——此前用户改过的角色提示词只存内存，进程一死就静默变回内置文案且没有任何提示。现在落库到 `prompt` 事实（`id = prompt:<role>`），与阶段/得分点覆盖层同一套持久化；
- **技能库可以新建、编辑、删除了**——此前 `skill_add` 只登记事实、不写正文，面板存不了技能。现在按上游 `SKILL.md` frontmatter 语义落到应用自己的技能库，内置技能拒改拒删并给出原因，不静默跳过。

## ✨ 新功能

### RedTeam 控制台：多页签全量迁移

- **资产测绘**：C 段侧栏（资产数 / 端口数 / 被动·主动构成）、搜索（IP / 域名 / 指纹，回车提交）、服务与端口过滤、来源过滤（来源不限 / 仅被动 / 仅主动）、五种排序（易打性优先 / 端口多优先 / 最新发现 / 待测优先 / 按 IP）；
- **列表与图谱双视图**：节点种类与配色对齐上游（C 段 `#6366f1`、存活资产 `#10b981`、离线资产 `#9ca3af`、开放端口 `#f59e0b`、域名 `#8b5cf6`）；
- **资产详情**：主机名、C 段、首见/末见、开放端口与服务、指纹、最近 8 条采集溯源，每条都带被动/主动来源标记；
- **智能体提示词**：角色列表 + 正文编辑器，保存 / 恢复内置；已改过的角色标「已改」；
- **技能库**：列表 + 编辑器（名称、角色、启用开关、描述、whenToUse、正文）。

### 对话工作台补两个入口

- **仓库入口**：与模型选择、浏览器同一条工作台条线上，展示改动文件数，可直接进 Git 面板；
- **运行日志入口**：同一位置，直达 Harness 运行日志。

### 红队工具面补齐

新增 6 个工具动作（83 → 89，仍是上游 53 个 `redteam_*` 工具的超集）：

`prompts` · `role_prompt_save` · `skill_list` · `skill_get` · `skill_save` · `skill_delete`

## 🐛 修复

- **「继续」后任务显示完成却没有回答**：`TurnRunner` 加了失败关闭分支——模型既没给出可展示文本也没发起工具调用时，本轮判失败并说明原因，不再当作正常结束；
- **工具轮数耗尽被当成成功**：达到最大工具轮数时返回明确失败（`已达到最大工具轮数（N），任务尚未确认完成`），不再静默收尾；
- **工具无输出时面板空白**：工具返回空文本时补一条明确说明，不再出现「跑完了但什么都没有」；
- **工具输出截断**：超长输出保留头部并附显式截断提示，不再无提示地砍掉尾部。

---

## 🧱 内部

- 新增 `core/model/RedTeamConsoleModel`：面板投影层（纯 Kotlin）。过滤、排序、网段、统计、图谱口径与上游 `listAssets` 一一对应；面板直接读结构化行，不去正则解析工具输出——工具输出改一个字面板就瞎了；
- 事实库新增 `byKinds` 批量读：`recent` 的 500 条上限对面板不够（上游默认就展示 400 台资产），越过会被显示成「记录变少了」；
- 图谱改用确定性环形布局：移动端跑力导向迭代会掉帧，且布局每次都在抖，用户点开的瞬间看到的位置和下一眼不一样；
- 单元测试 918 → 1017（新增控制台投影 10 项、角色提示词与技能库 6 项）。

### 与上游的有意分歧

- 时间戳存 epoch 毫秒，不是 ISO 字符串；
- 不另建靶标表：一个绑定了红队模式的会话就是一个靶标，面板用会话选择代替上游的 `current` 指针；
- 不记录 `scan_run` 批次表（批次元信息不落库）；
- 知识库按会话隔离，不跨靶标共享 POC。
